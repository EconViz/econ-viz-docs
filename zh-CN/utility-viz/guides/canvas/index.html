    Canvas 画布

    Canvas 是核心的绘图画布。它管理一张 matplotlib 图，样式遵循微观经济学教科书的惯例：只画第一象限、坐标轴末端有箭头、标签用 LaTeX 绘制、不显示数字刻度。

    构造函数

    Canvas(
    x_max: float,
    y_max: float,
    x_label: str,
    y_label: str,
    title: str | Label | None,
    dpi: int,
    x_label_pos: LabelPosition | str,
    y_label_pos: LabelPosition | str,
    theme: Theme | None,
    font: str | Sequence[str] | None,
    math_font: str | None,
    axis_stroke: Stroke | None,
    x_axis_stroke: Stroke | None,
    y_axis_stroke: Stroke | None,
    x_axis: Axis | None,
    y_axis: Axis | None,
) → Canvas
    x_maxfloat默认值： 10.0

    横轴上限

    y_maxfloat默认值： 10.0

    纵轴上限

    x_labelstr默认值： 'X'

    横轴 Axis(label=...) 的简写

    y_labelstr默认值： 'Y'

    纵轴 Axis(label=...) 的简写

    titlestr 或 Label 或 None默认值： None

    图形标题

    dpiint默认值： 300

    位图导出分辨率（限制在 1–1200）

    x_label_posLabelPosition 或 str默认值： LabelPosition.RIGHT

    Axis(label_position=...) 的简写：箭头上方、右侧或下方

    y_label_posLabelPosition 或 str默认值： LabelPosition.TOP

    Axis(label_position=...) 的简写：箭头左侧、上方或右侧

    themeTheme 或 None默认值： None

    配色与样式主题

    fontstr 或 Sequence[str] 或 None默认值： None

    所有文字使用的字体或候选字体列表

    math_fontstr 或 None默认值： None

    数学字体：dejavusans、dejavuserif、cm、stix 或 stixsans

    axis_strokeStroke 或 None默认值： None

    同时设置两轴的粗细、线条样式、颜色与箭头样式

    x_axis_strokeStroke 或 None默认值： None

    横轴的单独覆盖，是 Axis(stroke=...) 的简写

    y_axis_strokeStroke 或 None默认值： None

    纵轴的单独覆盖，是 Axis(stroke=...) 的简写

    x_axisAxis 或 None默认值： None

    横轴的标签、标签位置与线条

    y_axisAxis 或 None默认值： None

    纵轴的标签、标签位置与线条

    查看示例 
    from utility_viz import ArrowStyle, Axis, Canvas, Stroke, themes

cvs = Canvas(
    x_max=20,
    y_max=15,
    title=r"Cobb-Douglas $x^{0.5} y^{0.5}$",
    dpi=300,
    font="DejaVu Sans",
    math_font="stix",
    axis_stroke=Stroke(width=1.0, arrow=ArrowStyle.TRIANGLE),
    # "top"、"right" 或 "bottom"
    x_axis=Axis(label="x", label_position="right"),
    # "left"、"top" 或 "right"
    y_axis=Axis(label="y", label_position="top"),
    theme=themes.default,
)

    同一项设置给了两次时，以 Axis 的字段为准。坐标轴线条的优先顺序由高到低是 Axis.stroke、x_axis_stroke、axis_stroke、x_line_style / x_arrow_style、theme.axis_stroke。

    方法

    所有绘图方法都会返回 self，所以可以串接调用。

    效用曲线

    画出效用函数的无差异曲线。levels 传入整数会自动决定曲线的间距，也可以传入一组效用值，例如用 levels.around(eq.utility, n=5) 让曲线分布在最优点周围。

    Canvas.add_utility(
    func: Callable,
    levels: int | list,
    color: str | None,
    linewidth: float | None,
    show_rays: bool,
    show_kinks: bool,
    kink_radius: float,
    show_bliss: bool,
    label: str | None,
    show_ic_labels: bool,
    ic_label_fmt: str,
    stroke: Stroke | None,
    ray_stroke: Stroke | None,
    kink_marker: Marker | None,
    bliss_marker: Marker | None,
    ic_label: Label | None,
    bliss_label: str | Label | None,
    highlight_level: float | None,
    secondary_stroke: Stroke | None,
    label_style: str,
    **kwargs,
) → Canvas
    funcCallable必填

    要绘制的效用模型。

    levelsint 或 list默认值： 3

    曲线数量，或指定的效用水平列表。

    colorstr 或 None默认值： None

    覆盖颜色；未指定时沿用主题。

    linewidthfloat 或 None默认值： None

    覆盖线条粗细；未指定时沿用主题。

    show_raysbool默认值： False

    为具有折点的效用模型画出折点轨迹射线。

    show_kinksbool默认值： False

    标出各条无差异曲线的折点。

    kink_radiusfloat默认值： 1.0

    折点标记的大小倍率。

    show_blissbool默认值： True

    若模型具有餍足点，显示其标记。

    labelstr 或 None默认值： None

    可选的 LaTeX 数学标签。

    show_ic_labelsbool默认值： False

    在曲线末端显示效用标签。

    ic_label_fmtstr默认值： '{:.2g}'

    数值效用标签的格式字符串。

    strokeStroke 或 None默认值： None

    线条样式，优先于单独的颜色、粗细与线型简写。

    ray_strokeStroke 或 None默认值： None

    射线的线条样式；未指定时沿用主题。

    kink_markerMarker 或 None默认值： None

    折点标记样式；未指定时沿用主题。

    bliss_markerMarker 或 None默认值： None

    餍足点标记样式；未指定时沿用主题。

    ic_labelLabel 或 None默认值： None

    无差异曲线末端标签的样式。

    bliss_labelstr 或 Label 或 None默认值： None

    餍足点的文字或 Label 对象。

    highlight_levelfloat 或 None默认值： None

    强调最接近此效用水平的曲线。

    secondary_strokeStroke 或 None默认值： None

    主要曲线以外的次要曲线样式。

    label_stylestr默认值： 'numeric'

    使用 numeric 数值或 ordinal 教科书式序数标签。

    **kwargs其他关键字参数

    传给底层绘图或导出函数的其他选项。

    主要与次要曲线

    把均衡效用传给 highlight_level，即可强调最接近的效用水平，不需要自己再画第二组等高线。其余曲线使用 theme.secondary_ic_stroke，也可以用 secondary_stroke 单独指定。

    from utility_viz import Canvas, Stroke, levels, solve
from utility_viz.models import CobbDouglas

model = CobbDouglas(0.5, 0.5)
eq = solve(model, px=2, py=3, income=30)
lvls = levels.around(eq.utility, n=5)

(
    Canvas(x_max=20, y_max=15)
    .add_utility(
        model,
        levels=lvls,
        highlight_level=eq.utility,
        secondary_stroke=Stroke(width=1, opacity=0.35),
        show_ic_labels=True,
        label_style="ordinal",
    )
    .add_budget(2, 3, 30, fill=True)
    .add_equilibrium(eq)
)

    label_style="numeric" 显示格式化后的效用值；"ordinal" 则使用教科书常见的 \(u_1,u_2,\ldots\)。标签会跟随曲线在该处的角度，并避开可见范围的边界。

    • 强调前——每个效用水平的视觉权重相同。
    • 强调后——均衡效用水平成为主要曲线。
    • 序数标签——曲线标为 \(u_1,u_2,\ldots\)。

    预算线

    画出预算线 \(p_x x + p_y y = I\)。设置 fill=True 会在预算线下方的可行集加上阴影。

    Canvas.add_budget(
    px: float,
    py: float,
    income: float,
    color: str | None,
    linewidth: float | None,
    linestyle: str | None,
    label: str | None,
    fill: bool | Fill,
    fill_alpha: float | None,
    stroke: Stroke | None,
) → Canvas
    pxfloat必填

    商品 X 的价格，必须大于 0。

    pyfloat必填

    商品 Y 的价格，必须大于 0。

    incomefloat必填

    总预算，必须大于 0。

    colorstr 或 None默认值： None

    覆盖颜色；未指定时沿用主题。

    linewidthfloat 或 None默认值： None

    覆盖线条粗细；未指定时沿用主题。

    linestylestr 或 None默认值： None

    Matplotlib 线条样式；未指定时沿用主题。

    labelstr 或 None默认值： None

    可选的 LaTeX 数学标签。

    fillbool 或 Fill默认值： False

    设为 True 填满可行集，或传入 Fill 指定颜色与透明度。

    fill_alphafloat 或 None默认值： None

    填色透明度；Fill 中的透明度设置优先。

    strokeStroke 或 None默认值： None

    线条样式，优先于单独的颜色、粗细与线型简写。

    均衡点

    在最优消费组合画上均衡点，并画出到两轴的垂直虚线。eq 传入 solve() 的返回值；show_ray=True 会同时画出通过原点的扩展路径。

    Canvas.add_equilibrium(
    eq: Equilibrium,
    color: str | None,
    markersize: float | None,
    label: str | Label | None,
    drop_dashes: bool,
    show_ray: bool,
    drop_stroke: Stroke | None,
    ray_stroke: Stroke | None,
    marker: Marker | None,
) → Canvas
    eqEquilibrium必填

    solve() 返回的均衡结果。

    colorstr 或 None默认值： None

    覆盖颜色；未指定时沿用主题。

    markersizefloat 或 None默认值： None

    标记大小；未指定时沿用主题。

    labelstr 或 Label 或 None默认值： 'x^*'

    可选的 LaTeX 数学标签。

    drop_dashesbool默认值： True

    画出通往两轴的垂直辅助线。

    show_raybool默认值： False

    画出从原点通过均衡点的射线。

    drop_strokeStroke 或 None默认值： None

    通往两轴的辅助线样式。

    ray_strokeStroke 或 None默认值： None

    射线的线条样式；未指定时沿用主题。

    markerMarker 或 None默认值： None

    标记的颜色、大小与形状；未指定时沿用主题。

    射线

    从原点画一条斜率为 slope（\(\mathrm{d}y/\mathrm{d}x\)）的虚线射线，常用来表示扩展路径或固定的消费比例。

    Canvas.add_ray(
    slope: float,
    color: str | None,
    linewidth: float | None,
    stroke: Stroke | None,
) → Canvas
    slopefloat必填

    射线斜率，以 \(\mathrm{d}y/\mathrm{d}x\) 表示。

    colorstr 或 None默认值： None

    覆盖颜色；未指定时沿用主题。

    linewidthfloat 或 None默认值： None

    覆盖线条粗细；未指定时沿用主题。

    strokeStroke 或 None默认值： None

    线条样式，优先于单独的颜色、粗细与线型简写。

    标记点

    标记任意一点，例如要与最优点比较的消费组合。label 会以 LaTeX 数学模式显示；要移动标签或改样式时，传入 Label。

    Canvas.add_point(
    x: float,
    y: float,
    label: str | Label | None,
    color: str | None,
    markersize: float | None,
    offset: tuple[float, float] | None,
    marker: Marker | None,
) → Canvas
    xfloat必填

    点的水平坐标。

    yfloat必填

    点的垂直坐标。

    labelstr 或 Label 或 None默认值： None

    可选的 LaTeX 数学标签。

    colorstr 或 None默认值： None

    覆盖颜色；未指定时沿用主题。

    markersizefloat 或 None默认值： None

    标记大小；未指定时沿用主题。

    offsettuple[float, float] 或 None默认值： None

    标签位移 (dx, dy)，单位为点；Label 的位置或位移设置优先。

    markerMarker 或 None默认值： None

    标记的颜色、大小与形状；未指定时沿用主题。

    显示与保存

    show() 会打开交互窗口。save() 根据扩展名决定格式，支持 .png、.pdf、.svg，以及输出 TikZ 的 .tex。save() 也会释放 matplotlib 的资源，所以要放在最后调用。

    Canvas.show() → None
    Canvas.save(
    path: str,
    **kwargs,
) → None
    pathstr必填

    输出路径；扩展名决定 PNG、PDF、SVG 或 TikZ 格式。

    **kwargs其他关键字参数

    传给底层绘图或导出函数的其他选项。

    # 交互窗口
cvs.show()
# .png / .pdf / .svg / .tex
cvs.save("figure.png")

    样式

    每一类元素都有自己的样式对象。没有指定的字段会沿用主题默认值，所以只需设置想改的部分。

    Stroke

    线条粗细、线条样式、颜色、箭头

    主题默认值 — theme.budget_stroke、theme.ic_stroke 等

    Marker

    点的颜色、大小、形状

    主题默认值 — theme.eq_marker、theme.point_marker 等

    Label

    标签文字、位置、偏移、颜色、大小、是否显示

    主题默认值 — theme.point_label、theme.ic_label 等

    Fill

    阴影颜色与透明度

    主题默认值 — theme.budget_fill

    Axis

    单个坐标轴的标签、标签位置与线条

    主题默认值 — 无

    Legend

    图例的位置、大小、外框、列数

    主题默认值 — theme.legend

    每个对象也都有 opacity，从 0（透明）到 1（不透明）。

    from utility_viz import Canvas, Fill, Label, Marker, Stroke

(
    Canvas(x_max=20, y_max=15)
    .add_utility(
        model,
        levels=lvls,
        ic_label=Label(text="U={:.1f}", position="top"),
    )
    .add_budget(
        2.0,
        3.0,
        30.0,
        stroke=Stroke(color="black"),
        fill=Fill(color="lightgrey", opacity=0.4),
    )
    .add_equilibrium(
        eq,
        marker=Marker(color="#C0392B", shape="s"),
        label=Label(position="bottom-left", offset=8),
    )
    .add_point(
        12.0, 2.0, label=Label(text="A", position="left")
    )
    .save("styles.png")
)

    建议用 Stroke 设置线条样式。另外的 color、linewidth、linestyle 参数仍可作为简写使用，画出来的结果相同。标签默认沿用所属点的 Marker 颜色，除非另外指定；位置可用 top、bottom、left、right 与 top-right 等四个角落，Label(visible=False) 可隐藏标签。

    文字与图例

    所有文字都能传入 Label：坐标轴标签通过 Axis(label=...)，原点通过 origin_label，标题通过 title。图例默认会放在最不遮挡图形的位置，四个角都会遮挡时就移到图外；也可以用 Legend 指定图内的角落（"upper left" 等），或图外的上下左右（"top"、"bottom"、"left"、"right"）。

    from utility_viz import Axis, Canvas, Label, Legend

cvs = Canvas(
    title=Label(text="Cobb-Douglas", fontsize=13),
    x_axis=Axis(label=Label(text="x_1", fontsize=16)),
    origin_label=Label(visible=False),
)
cvs.show_legend(legend=Legend(position="bottom", fontsize=10))

    下方的线条样式与箭头样式，坐标轴通过 x_* 与 y_* 参数设置，其他线条则通过 Stroke 应用。

    线条样式

    坐标轴可使用 LineStyle.SOLID、DASHED、DOTTED 或 DASHDOT。也可以直接传入对应的 solid、dashed、dotted 或 dashdot 字符串。其他线条则通过 Stroke(style=...) 设置。

    import matplotlib.pyplot as plt

from utility_viz import Canvas, LineStyle

styles = [
    LineStyle.SOLID,
    LineStyle.DASHED,
    LineStyle.DOTTED,
    LineStyle.DASHDOT,
]

fig, axes = plt.subplots(2, 2, figsize=(7, 7))
for ax, style in zip(axes.flat, styles):
    Canvas(
        title=style.value,
        x_line_style=style,
        y_line_style=style,
        fig=fig,
        ax=ax,
    )

fig.tight_layout()
fig.savefig("line_styles.png", dpi=160, transparent=True)

    箭头样式

    坐标轴可使用 ArrowStyle.SIMPLE、TRIANGLE、FANCY 或 WEDGE。其他可见线条则通过 Stroke(arrow=...) 添加相同的箭头样式。

    import matplotlib.pyplot as plt

from utility_viz import ArrowStyle, Canvas

styles = [
    ArrowStyle.SIMPLE,
    ArrowStyle.TRIANGLE,
    ArrowStyle.FANCY,
    ArrowStyle.WEDGE,
]

fig, axes = plt.subplots(2, 2, figsize=(7, 7))
for ax, style in zip(axes.flat, styles):
    Canvas(
        title=style.name.title(),
        x_arrow_style=style,
        y_arrow_style=style,
        fig=fig,
        ax=ax,
    )

fig.tight_layout()
fig.savefig("arrow_styles.png", dpi=160, transparent=True)

    路径、效应分解、DemandDiagram、Figure 与 EdgeworthBox 也可以使用 Stroke。未指定的字段会沿用当前主题。

    串接调用

    Canvas(x_max=20, y_max=15).add_utility(
    model, levels=lvls
).add_budget(2.0, 3.0, 30.0, fill=True).add_equilibrium(
    eq, show_ray=True
).save(
    "figure.png"
)
