    Canvas 画布

    Canvas 以 matplotlib 的 Figure 与 Axes 为基础，提供无差异曲线、预算线与均衡点等图层。

    构造函数

    Canvas
    x_maxfloat默认值： 10

    横轴上限。

    y_maxfloat默认值： 10

    纵轴上限。

    x_labelstr默认值： "X"

    横轴末端的标签。

    y_labelstr默认值： "Y"

    纵轴末端的标签。

    titlestr | None默认值： None

    图形标题。

    dpiint默认值： 300

    位图导出分辨率，限制在 1–1200 之间。

    x_label_posstr默认值： "right"

    横轴标签相对箭头的位置，也接受 LabelPosition（参见x_label_pos 值）。

    y_label_posstr默认值： "top"

    纵轴标签相对箭头的位置（参见y_label_pos 值）。

    fontstr默认值： None

    所有文字使用的通用字体："sans"（默认）、"serif" 或 "mono"。已安装的字体名称（如 "Arial"）会报错，请改用 fonts。

    fontsTextFonts默认值： None

    取代通用字体的字体文件，如 TextFonts(serif="MyFont-Regular.otf")。每个字段可给一个文件或文件列表（常规、粗体等）；没给的字段沿用 DejaVu 默认。系统字体不会被搜索，请直接给路径。

    math_fontMathFont | str默认值： None

    OpenType 数学字体或其文件路径，如 STIX Two Math，经由 glyphkit 排版数学式。未设置时由 matplotlib 排版。旧的字体组名称（stix、cm、dejavusans）会报错。

    axis_strokeStroke默认值： theme

    同时设置两轴的粗细、线条样式、颜色与箭头（详见样式）。

    x_axis_strokeStroke默认值： None

    单独覆盖横轴。

    y_axis_strokeStroke默认值： None

    单独覆盖纵轴。

    themeTheme默认值： themes.default

    配色与样式主题（详见主题与设置）。

    创建画布，并设置坐标范围、轴标签、字体、线条样式与主题。未明确传入的视觉设置取自当前的 Config 与 Theme。

    "top"

    箭头上方

    "right"

    箭头右侧

    "bottom"

    箭头下方

    值 位置
    "left" 箭头左侧
    "top" 箭头上方
    "right" 箭头右侧

    绘图方法

    add_* 方法在当前的画布添加图层，并返回同一个 Canvas，因此可链式调用（详见链式调用）。

    Canvas.add_utility
    levelsint | list默认值： 3

    曲线条数或效用值列表；例如 levels.around(eq.utility, n=5) 会在均衡效用附近选取五个水平。

    highlight_levelfloat | None默认值： None

    焦点效用值。绘制时选择最接近的曲线，以主要样式显示。

    secondary_strokeStroke | None默认值： None

    其他曲线的样式；省略时使用 theme.secondary_ic_stroke。

    show_ic_labelsbool默认值： False

    显示曲线标签。标签沿曲线切线旋转，并保持在可见绘图区内。

    label_stylestr默认值： "numeric"

    "numeric" 显示效用值；"ordinal" 按效用递增顺序显示 \(u_1, u_2, \ldots\)。

    绘制无差异曲线。

    lvls = levels.around(eq.utility, n=5)
cvs.add_utility(
    model,
    levels=lvls,
    highlight_level=eq.utility,
    show_ic_labels=True,
    label_style="ordinal",
)

    from utility_viz import Canvas, Config, levels, solve
from utility_viz.models import CobbDouglas

# 载入图形设置
Config.load("econ-viz.toml").use()

model = CobbDouglas(alpha=0.5, beta=0.5)
eq = solve(model, px=2.0, py=3.0, income=30.0)

# 斜体的 x 与 y
cvs = Canvas(x_max=20, y_max=15, x_label="$x$", y_label="$y$")
# 围绕最优点的三条曲线
cvs.add_utility(model, levels=levels.around(eq.utility, n=3))
cvs.save("add_utility.png")


    Canvas.add_budget
    fillbool | Fill默认值： False

    True 使用主题的阴影设置；传入 Fill 可覆盖阴影颜色与透明度。

    strokeStroke | None默认值： None

    统一设置预算线的颜色、线宽、线型与透明度，优先于 color、linewidth、linestyle 等简写参数（详见样式）。

    labelstr | None默认值： None

    图例文字；调用 show_legend() 后才会显示图例。

    绘制预算线 \(p_x x + p_y y = I\)。

    from utility_viz import Canvas, Config

# 载入图形设置
Config.load("econ-viz.toml").use()

# 斜体的 x 与 y
cvs = Canvas(x_max=20, y_max=15, x_label="$x$", y_label="$y$")
# 预算线与可行集合
cvs.add_budget(2.0, 3.0, 30.0, fill=True)
cvs.save("add_budget.png")

    Canvas.add_equilibrium
    drop_dashesbool默认值： True

    显示至两轴的投影线。

    show_raybool默认值： False

    显示通过原点与均衡点的射线。

    markerMarker | None默认值： None

    均衡点的标记样式（详见样式）。

    标记 solve() 返回的最优消费组合。

    from utility_viz import Canvas, Config, levels, solve
from utility_viz.models import CobbDouglas

# 载入图形设置
Config.load("econ-viz.toml").use()

model = CobbDouglas(alpha=0.5, beta=0.5)
eq = solve(model, px=2.0, py=3.0, income=30.0)

# 斜体的 x 与 y
cvs = Canvas(x_max=20, y_max=15, x_label="$x$", y_label="$y$")
cvs.add_utility(model, levels=levels.around(eq.utility, n=3))
cvs.add_budget(2.0, 3.0, 30.0, fill=True)
# 最优点与两条辅助虚线
cvs.add_equilibrium(eq)
cvs.save("add_equilibrium.png")

    Canvas.add_ray

    绘制通过原点、斜率为 slope（\(\mathrm{d} y / \mathrm{d} x\)）的射线，用于标记扩张路径或固定比例。

    from utility_viz import Canvas, Config, levels, solve
from utility_viz.models import CobbDouglas

# 载入图形设置
Config.load("econ-viz.toml").use()

model = CobbDouglas(alpha=0.5, beta=0.5)
eq = solve(model, px=2.0, py=3.0, income=30.0)

# 斜体的 x 与 y
cvs = Canvas(x_max=20, y_max=15, x_label="$x$", y_label="$y$")
cvs.add_utility(model, levels=levels.around(eq.utility, n=3))
cvs.add_budget(2.0, 3.0, 30.0)
cvs.add_equilibrium(eq)
# 过原点与最优点的射线
cvs.add_ray(eq.y / eq.x)
cvs.save("add_ray.png")

    Canvas.add_point
    labelstr | Label | None默认值： None

    标记文字，可传入字符串或 Label。

    offsettuple | None默认值： None

    文字相对标记点的位移，单位为 pt。

    markerMarker | None默认值： None

    标记样式。

    在指定坐标标记点。

    from utility_viz import Canvas, Config, Label, levels, solve
from utility_viz.models import CobbDouglas

# 载入图形设置
Config.load("econ-viz.toml").use()

model = CobbDouglas(alpha=0.5, beta=0.5)
eq = solve(model, px=2.0, py=3.0, income=30.0)

# 斜体的 x 与 y
cvs = Canvas(x_max=20, y_max=15, x_label="$x$", y_label="$y$")
# 一条无差异曲线 u = 5
cvs.add_utility(model, levels=[5.0])
cvs.add_budget(2.0, 3.0, 30.0)
# 与预算线交于两点
# 以 Label 放在点旁
cvs.add_point(
    3.17, 7.89, label=Label(text="A", position="top-right")
)
cvs.add_point(
    11.83, 2.11, label=Label(text="B", position="top-right")
)
cvs.save("add_point.png")

    Canvas.show
Canvas.save

    show() 打开交互窗口；save() 根据扩展名导出文件（详见导出），并释放对应的 matplotlib 图形，因此应最后调用。

    from utility_viz import Canvas, Config, levels, solve
from utility_viz.models import CobbDouglas

# 载入图形设置
Config.load("econ-viz.toml").use()

model = CobbDouglas(alpha=0.5, beta=0.5)
eq = solve(model, px=2.0, py=3.0, income=30.0)

# 斜体的 x 与 y
cvs = Canvas(x_max=20, y_max=15, x_label="$x$", y_label="$y$")
cvs.add_utility(model, levels=levels.around(eq.utility, n=3))
cvs.add_budget(2.0, 3.0, 30.0, fill=True)
# 均衡点与扩张路径
cvs.add_equilibrium(eq, show_ray=True)
cvs.save("show_save.png")

    样式

    LineStyle 定义线型，ArrowStyle 定义箭头样式，Stroke 统一设置线宽、线型、颜色与箭头，可应用于坐标轴、预算线、路径与投影线。

    线条样式

    LineStyle
    SOLIDLineStyle

    实线。

    DASHEDLineStyle

    虚线。

    DOTTEDLineStyle

    点线。

    DASHDOTLineStyle

    点划线。

    提供实线、虚线、点线与点画线（参见四种线条样式）。坐标轴接受枚举值或对应字符串；其他线条通过 Stroke(style=...) 设置。 LineStyle 就是 MosaicKit 的 DashStyle，沿用旧名称。

    from mosaickit import CanvasGrid

from utility_viz import Canvas, Config, LineStyle

# 载入图形设置
Config.load("econ-viz.toml").use()

styles = [
    LineStyle.SOLID,
    LineStyle.DASHED,
    LineStyle.DOTTED,
    LineStyle.DASHDOT,
]
titles = ["实线", "虚线", "点线", "点划线"]
panels = [
    Canvas(
        title=title,
        x_label="$x$",
        y_label="$y$",
        x_label_pos="bottom",
        x_line_style=style,
        y_line_style=style,
    )
    for style, title in zip(styles, titles)
]
for panel in panels:
    # 小画布
    panel.spec = panel.spec.replace(width=2.2, height=2.0)
CanvasGrid([panels]).save("line_styles.png")

    箭头样式

    ArrowStyle
    SIMPLEArrowStyle

    开口箭头（->）。

    TRIANGLEArrowStyle

    实心三角形（-|>），默认值。

    FANCYArrowStyle

    弯曲、渐细的箭头。

    WEDGEArrowStyle

    细楔形箭头。

    提供四种箭头样式（参见四种箭头样式）。坐标轴通过 x_arrow_style、y_arrow_style 设置；其他线条通过 Stroke(arrow=...) 设置。 ArrowStyle 是 MosaicKit 的；SIMPLE 即 OPEN，仍接受 "->" 与 "-|>"。

    from mosaickit import CanvasGrid

from utility_viz import ArrowStyle, Canvas, Config

# 载入图形设置
Config.load("econ-viz.toml").use()

styles = [
    ArrowStyle.SIMPLE,
    ArrowStyle.TRIANGLE,
    ArrowStyle.FANCY,
    ArrowStyle.WEDGE,
]
titles = ["简单", "三角形", "花式", "楔形"]
panels = [
    Canvas(
        title=title,
        x_label="$x$",
        y_label="$y$",
        x_label_pos="bottom",
        x_arrow_style=style,
        y_arrow_style=style,
    )
    for style, title in zip(styles, titles)
]
for panel in panels:
    # 小画布
    panel.spec = panel.spec.replace(width=2.2, height=2.0)
CanvasGrid([panels]).save("arrow_styles.png")

    Stroke

    Stroke(
    width=float,
    style=LineStyle,
    color=str,
    arrow=ArrowStyle,
    opacity=float
)

    设置线宽、线型、颜色、箭头与透明度。未指定的字段沿用当前主题。opacity 的有效范围为 0 至 1。

    Axis

    Axis

    集中设置单一坐标轴的标签、标签位置与线条。Canvas、Figure、DemandDiagram 与 EdgeworthBox 均接受 x_axis 与 y_axis。若同时传入简写参数，Axis 中已设置的字段优先。

    from utility_viz import Axis, Canvas, Label, Stroke

cvs = Canvas(
    x_axis=Axis(
        label=Label(text="x_1", fontsize=16),
        label_position="bottom",
        stroke=Stroke(width=1.2),
    ),
    y_axis=Axis(label="x_2"),
)

    Marker 与 Label

    Marker

    设置标记点的颜色、大小、形状与透明度。shape 接受 matplotlib 的标记字符串，例如 "o"、"s"、"^"、"D" 与 "*"。

    Label

    设置文字、位置、位移、颜色、字号、可见性与透明度。位置可为上、下、左、右或四个角落；Label(visible=False) 隐藏对应文字。

    from utility_viz import Label, Marker

cvs.add_equilibrium(
    eq,
    marker=Marker(shape="s", size=8),
    label=Label(position="bottom-left", offset=8),
)
cvs.add_point(
    12,
    2,
    marker=Marker(color="black", shape="D"),
    label=Label(text="A", position="left", fontsize=14),
)

    top、bottom、left 与 right 会在标签自动定位之后再微调位置：可传入点数，或带单位的字符串，例如 "10pt"、"0.5em"（以标签字号为单位）或 "2mm"。位置仍由自动定位决定，之后加入的标签也会避开移动后的标签。在 econ-viz.toml 的 [utility.label.<name>] 中写入 top = "2pt"，可为该类标签设置默认值（单位可用 pt、mm、cm 或 in，不支持 em）；标签自身指定的值会取代该方向的默认值。未设置微调时，所有图形保持不变。

    from utility_viz import Label

cvs.add_equilibrium(eq, label=Label(top="10pt"))
cvs.add_point(5, 3, label=Label(text="A", left="6pt"))

    Fill

    Fill

    设置阴影区域的颜色与透明度。alpha 是 opacity 的兼容简写；同一次调用不得传入不同的 alpha 与 opacity。

    from utility_viz import Fill

cvs.add_budget(
    2,
    3,
    30,
    fill=Fill(color="lightgrey", opacity=0.4),
)

    链式调用

    add_* 方法支持链式调用，最后以 save() 导出：

    Canvas(x_max=20, y_max=15).add_utility(
    model, levels=lvls
).add_budget(2.0, 3.0, 30.0, fill=True).add_equilibrium(
    eq, show_ray=True
).save(
    "figure.png"
)
