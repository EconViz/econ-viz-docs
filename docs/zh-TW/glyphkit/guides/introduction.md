# 簡介

<span id="sec-intro"></span>

`glyphkit` 把呼叫端提供的字型與文字轉成不可變的排版資料。它負責選擇字型、處理 Unicode 文字的字形、排列段落與數學式、測量文字、擷取字形輪廓，以及建立字型子集。繪圖套件可把同一份結果用於 SVG、HTML、點陣圖或其他繪圖端。

GlyphKit 不會繪圖、製作動畫、建立場景、下載字型、解讀授權條款，也不會寫出檔案。字型必須透過路徑、位元組或資料流明確傳入。搜尋系統字型是選用功能，只有呼叫端主動要求時才會執行。

## 放在整套工具的哪裡

- 繪圖端需要精確的字形位置、範圍、路徑或可攜式字型資料時，使用 GlyphKit。
- 文字需要放進場景並製作動畫時，接到 `kinetickit`。
- 像素、向量元素、檔案與 DPI 仍由最後的繪圖端處理。

一般流程很短：建立 `FontLibrary`，用 `Paragraph` 與 `TextStyle` 描述文字，呼叫 `layout()`，再把 `TextLayout` 交給使用端。

## 每個結果的共同點

每個結果都是不可變的值，由一般資料組成：tuple、數字、字串與凍結的資料類別。`to_data()` 把支援的值轉成有版本的純資料，`from_data()` 再把它驗證回來。GlyphKit 沒有隱藏的全域狀態；字型面用位元組的 SHA-256 與字型集合索引識別，而不是路徑。
