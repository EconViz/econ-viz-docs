# 简介

<span id="sec-intro"></span>

`glyphkit` 把调用端提供的字体与文本转成不可变的排版数据。它负责选择字体、处理 Unicode 文本的字形、排列段落与数学式、测量文本、截取字形轮廓，以及创建字体子集。绘图软件包可把同一份结果用于 SVG、HTML、位图或其他绘图端。

GlyphKit 不会绘图、制作动画、创建场景、下载字体、解读授权条款，也不会写出文件。字体必须通过路径、字节或数据流明确传入。搜索系统字体是选用功能，只有调用端主动要求时才会运行。

## 放在整套工具的哪里

- 绘图端需要精确的字形位置、范围、路径或可携式字体数据时，使用 GlyphKit。
- 文本需要放进场景并制作动画时，接到 `kinetickit`。
- 像素、矢量元素、文件与 DPI 仍由最后的绘图端处理。

一般流程很短：创建 `FontLibrary`，用 `Paragraph` 与 `TextStyle` 描述文本，调用 `layout()`，再把 `TextLayout` 交给使用端。

## 每个结果的共同点

每个结果都是不可变的值，由一般数据组成：tuple、数字、字符串与冻结的数据类别。`to_data()` 把支持的值转成有版本的纯数据，`from_data()` 再把它验证回来。GlyphKit 没有隐藏的全域状态；字体面用字节的 SHA-256 与字体集合索引识别，而不是路径。
