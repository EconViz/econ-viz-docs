# 简介

<span id="sec-intro"></span>

`glyphkit` 把调用方提供的字体与文本转换成不可变的排版数据。它负责选择字体、处理 Unicode 文本的字形、排列段落与数学公式、测量文本、提取字形轮廓，以及创建字体子集。绘图库可以把同一份结果用于 SVG、HTML、位图或其他渲染器。

GlyphKit 不会绘图、制作动画、创建场景、下载字体、解读授权条款，也不会写入文件。字体必须通过路径、字节或数据流明确传入。搜索系统字体是可选功能，只有调用方主动要求时才会执行。

## 放在整套工具的哪里

- 渲染器需要精确的字形位置、范围、路径或可移植字体数据时，使用 GlyphKit。
- 文字需要放进场景并制作动画时，接到 `kinetickit`。
- 像素、矢量元素、文件与 DPI 仍由最终的渲染器处理。

一般流程很直接：创建 `FontLibrary`，用 `Paragraph` 与 `TextStyle` 描述文本，调用 `layout()`，再把 `TextLayout` 交给使用方。后面各章都会遵循这条分工边界。
