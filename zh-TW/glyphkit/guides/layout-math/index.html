    文字排版與數學式

    段落與測量

    layout_paragraph(library, paragraph) → TextLayout

    處理每個片段的字形，在合法的 Unicode 斷行位置換行，並回傳不可變的 TextLayout。library.layout(paragraph) 會把字型庫當成第一個引數來呼叫它。

    TextMeasurement(
    advance,
    logical_bounds,
    ink_bounds,
    baselines,
    horizontal_overflow,
    vertical_overflow,
)

    彙整排版結果的邏輯範圍與墨跡範圍、基線、行數與溢出，不繪製任何東西。layout.measure() 會回傳這樣一份。

    LineLayout(
    runs,
    baseline,
    advance,
    logical_bounds,
    ink_bounds,
    horizontal_overflow=0.0,
    source_range=None,
    explicitly_terminated=False,
    reading_order=(),
)

    排好的一行，包含字形組、基線、字幅、範圍、原文範圍，以及這一行是否在明確的換行處結束。

    TextStyle 帶著字族、字級、字重、斜體、語言、方向、間距與 OpenType 功能。一個段落可以混用多種樣式與文字系統。設定 max_width 會在 Unicode 斷行位置換行 {Unicode Consortium} (2026)；不設定則排成不受限制的一行。一行如何組成，見行的組成與間距。

    結構化數學式

    from glyphkit import FontLibrary, FontSource
from glyphkit.math import MathStyle, parse_math

library = FontLibrary.from_sources((FontSource.path("fonts/STIXTwoMath-Regular.otf"),))
formula = parse_math(r"U(x_1, x_2) = x_1^\alpha x_2^{1-\alpha}")
box = library.layout_math(formula, style=MathStyle(18, ("STIX Two Math",)))
print(box.bounds)


    parse_math(source, *, max_length=100000, max_depth=256, max_matrix_cells=10000) → MathNode
    sourcestr

    類 LaTeX 的原始文字。

    max_lengthint預設值： 100000

    輸入長度上限，以碼位計。

    max_depthint預設值： 256

    群組巢狀深度上限。

    max_matrix_cellsint預設值： 10000

    矩陣儲存格數量上限。

    把一套明確定義、類 LaTeX 的語法解析成由符號、上下標、分數、根號、括號、矩陣、重音符號與上下限組成的樹。語法列在數學語法。

    FontLibrary.layout_math(expression, *, style) → MathBox
    expressionMathNode

    parse_math 回傳的樹。

    styleMathStyle

    大小、數學字型與覆寫值。

    用 style.families 裡第一個字型的 OpenType MATH 常數排出算式。這個字型必須有 MATH 表。

    MathStyle(
    size,
    families,
    level='display',
    script_scale=None,
    script_script_scale=None,
    constants=...,
    letter_slant='normal',
)
    sizefloat

    整個算式的大小，使用排版單位。

    familiestuple[str, ...]

    先放數學字型字族，再放後備字族。第一個必須有 OpenType MATH 表。

    levelstr預設值： "display"

    "display"、"text"、"script" 或 "scriptscript"。

    script_scalefloat | None預設值： None

    取代 ScriptPercentScaleDown，為 (0, 1] 的比例。

    script_script_scalefloat | None預設值： None

    取代 ScriptScriptPercentScaleDown。

    constantsMapping[str, float]預設值： ...

    以名稱覆寫其他 MATH 常數，單位為 em。

    letter_slantstr預設值： "normal"

    用字族的斜體或傾斜字型繪製字母符號。

    控制數學字族、大小、上下標層級、字母的傾斜、上下標縮放比例，以及 OpenType MATH 常數的覆寫值。

    MathBox(
    kind,
    bounds,
    baseline,
    text_layout=None,
    children=(),
    rules=(),
    origin=(0.0, 0.0),
    source_range=None,
    glyph_id=None,
)

    排好的樹的一個節點。它有 kind、範圍、基線、每個子節點相對於父節點的 origin、放在 text_layout 裡的字形排版，以及可繪製的 rules。

    這是一套明確定義的類 LaTeX 子集，不是 TeX 直譯器。與字型相關的常數與字形變體來自 OpenType MATH 表 {Microsoft} (2025)。MathStyle 可以覆寫上下標縮放比例、具名的數學常數與字母使用的傾斜，這對 MATH 表不完整的字型很有用。

    繪圖端只要走訪這棵樹：把每個子節點的原點加到父節點的位置上，用字形輪廓畫出每個 text_layout，並把每條 rule 畫成從 start 到 end、粗細為 thickness 的線。畫出上圖的腳本就是這樣做的，大約四十行。
