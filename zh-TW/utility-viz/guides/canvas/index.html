    Canvas 畫布

    Canvas 以 matplotlib 的 Figure 與 Axes 為基礎，提供無異曲線、預算線與均衡點等圖層。

    建構函式

    Canvas
    x_maxfloat預設值： 10

    橫軸上限。

    y_maxfloat預設值： 10

    縱軸上限。

    x_labelstr預設值： "X"

    橫軸末端的標籤。

    y_labelstr預設值： "Y"

    縱軸末端的標籤。

    titlestr | None預設值： None

    圖形標題。

    dpiint預設值： 300

    點陣圖匯出解析度，限制在 1–1200 之間。

    x_label_posstr預設值： "right"

    橫軸標籤相對箭頭的位置，也接受 LabelPosition（參見x_label_pos 值）。

    y_label_posstr預設值： "top"

    縱軸標籤相對箭頭的位置（參見y_label_pos 值）。

    fontstr預設值： None

    所有文字使用的通用字型："sans"（預設）、"serif" 或 "mono"。已安裝的字型名稱（如 "Arial"）會報錯，請改用 fonts。

    fontsTextFonts預設值： None

    取代通用字型的字型檔，如 TextFonts(serif="MyFont-Regular.otf")。每個欄位可給一個檔案或檔案清單（一般、粗體等）；沒給的欄位沿用 DejaVu 預設。系統字型不會被搜尋，請直接給路徑。

    math_fontMathFont | str預設值： None

    OpenType 數學字型或其檔案路徑，如 STIX Two Math，經由 glyphkit 排版數學式。未設定時由 matplotlib 排版。舊的字型組名稱（stix、cm、dejavusans）會報錯。

    axis_strokeStroke預設值： theme

    同時設定兩軸的粗細、線條樣式、顏色與箭頭（詳見樣式）。

    x_axis_strokeStroke預設值： None

    單獨覆寫橫軸。

    y_axis_strokeStroke預設值： None

    單獨覆寫縱軸。

    themeTheme預設值： themes.default

    配色與樣式主題（詳見主題與設定）。

    建立畫布，並設定座標範圍、軸標籤、字型、線條樣式與主題。未明確傳入的視覺設定取自目前的 Config 與 Theme。

    "top"

    箭頭上方

    "right"

    箭頭右側

    "bottom"

    箭頭下方

    值 位置
    "left" 箭頭左側
    "top" 箭頭上方
    "right" 箭頭右側

    繪圖方法

    add_* 方法在目前的畫布加入圖層，並回傳同一個 Canvas，因此可串接呼叫（詳見串接呼叫）。

    Canvas.add_utility
    levelsint | list預設值： 3

    曲線條數或效用值清單；例如 levels.around(eq.utility, n=5) 會在均衡效用附近選取五個水準。

    highlight_levelfloat | None預設值： None

    焦點效用值。實際繪製時選取最接近的曲線，以主要樣式顯示。

    secondary_strokeStroke | None預設值： None

    其他曲線的樣式；省略時使用 theme.secondary_ic_stroke。

    show_ic_labelsbool預設值： False

    顯示曲線標籤。標籤沿曲線切線旋轉，並保留在可見繪圖區域內。

    label_stylestr預設值： "numeric"

    "numeric" 顯示效用值；"ordinal" 依效用遞增順序顯示 \(u_1, u_2, \ldots\)。

    繪製無異曲線。

    lvls = levels.around(eq.utility, n=5)
cvs.add_utility(
    model,
    levels=lvls,
    highlight_level=eq.utility,
    show_ic_labels=True,
    label_style="ordinal",
)

    from utility_viz import Canvas, Config, levels, solve
from utility_viz.models import CobbDouglas

# 載入圖形設定
Config.load("econ-viz.toml").use()

model = CobbDouglas(alpha=0.5, beta=0.5)
eq = solve(model, px=2.0, py=3.0, income=30.0)

# 斜體的 x 與 y
cvs = Canvas(x_max=20, y_max=15, x_label="$x$", y_label="$y$")
# 圍繞最適點的三條曲線
cvs.add_utility(model, levels=levels.around(eq.utility, n=3))
cvs.save("add_utility.png")


    Canvas.add_budget
    fillbool | Fill預設值： False

    True 使用主題的陰影設定；傳入 Fill 可覆寫陰影顏色與透明度。

    strokeStroke | None預設值： None

    統一設定預算線的顏色、線寬、線型與透明度，優先於 color、linewidth、linestyle 等簡寫參數（詳見樣式）。

    labelstr | None預設值： None

    圖例文字；呼叫 show_legend() 後才會顯示圖例。

    繪製預算線 \(p_x x + p_y y = I\)。

    from utility_viz import Canvas, Config

# 載入圖形設定
Config.load("econ-viz.toml").use()

# 斜體的 x 與 y
cvs = Canvas(x_max=20, y_max=15, x_label="$x$", y_label="$y$")
# 預算線與可行集合
cvs.add_budget(2.0, 3.0, 30.0, fill=True)
cvs.save("add_budget.png")

    Canvas.add_equilibrium
    drop_dashesbool預設值： True

    顯示至兩軸的投影線。

    show_raybool預設值： False

    顯示通過原點與均衡點的射線。

    markerMarker | None預設值： None

    均衡點的標記樣式（詳見樣式）。

    標記 solve() 回傳的最適消費組合。

    from utility_viz import Canvas, Config, levels, solve
from utility_viz.models import CobbDouglas

# 載入圖形設定
Config.load("econ-viz.toml").use()

model = CobbDouglas(alpha=0.5, beta=0.5)
eq = solve(model, px=2.0, py=3.0, income=30.0)

# 斜體的 x 與 y
cvs = Canvas(x_max=20, y_max=15, x_label="$x$", y_label="$y$")
cvs.add_utility(model, levels=levels.around(eq.utility, n=3))
cvs.add_budget(2.0, 3.0, 30.0, fill=True)
# 最適點與兩條輔助虛線
cvs.add_equilibrium(eq)
cvs.save("add_equilibrium.png")

    Canvas.add_ray

    繪製通過原點、斜率為 slope（\(\mathrm{d} y / \mathrm{d} x\)）的射線，用於標記擴張路徑或固定比例。

    from utility_viz import Canvas, Config, levels, solve
from utility_viz.models import CobbDouglas

# 載入圖形設定
Config.load("econ-viz.toml").use()

model = CobbDouglas(alpha=0.5, beta=0.5)
eq = solve(model, px=2.0, py=3.0, income=30.0)

# 斜體的 x 與 y
cvs = Canvas(x_max=20, y_max=15, x_label="$x$", y_label="$y$")
cvs.add_utility(model, levels=levels.around(eq.utility, n=3))
cvs.add_budget(2.0, 3.0, 30.0)
cvs.add_equilibrium(eq)
# 過原點與最適點的射線
cvs.add_ray(eq.y / eq.x)
cvs.save("add_ray.png")

    Canvas.add_point
    labelstr | Label | None預設值： None

    標記文字，可傳入字串或 Label。

    offsettuple | None預設值： None

    文字相對標記點的位移，單位為 pt。

    markerMarker | None預設值： None

    標記樣式。

    在指定座標標記點。

    from utility_viz import Canvas, Config, Label, levels, solve
from utility_viz.models import CobbDouglas

# 載入圖形設定
Config.load("econ-viz.toml").use()

model = CobbDouglas(alpha=0.5, beta=0.5)
eq = solve(model, px=2.0, py=3.0, income=30.0)

# 斜體的 x 與 y
cvs = Canvas(x_max=20, y_max=15, x_label="$x$", y_label="$y$")
# 一條無異曲線 u = 5
cvs.add_utility(model, levels=[5.0])
cvs.add_budget(2.0, 3.0, 30.0)
# 與預算線交於兩點
# 以 Label 放在點旁
cvs.add_point(
    3.17, 7.89, label=Label(text="A", position="top-right")
)
cvs.add_point(
    11.83, 2.11, label=Label(text="B", position="top-right")
)
cvs.save("add_point.png")

    Canvas.show
Canvas.save

    show() 開啟互動視窗；save() 依副檔名匯出檔案（詳見匯出），並釋放對應的 matplotlib 圖形，因此應最後呼叫。

    from utility_viz import Canvas, Config, levels, solve
from utility_viz.models import CobbDouglas

# 載入圖形設定
Config.load("econ-viz.toml").use()

model = CobbDouglas(alpha=0.5, beta=0.5)
eq = solve(model, px=2.0, py=3.0, income=30.0)

# 斜體的 x 與 y
cvs = Canvas(x_max=20, y_max=15, x_label="$x$", y_label="$y$")
cvs.add_utility(model, levels=levels.around(eq.utility, n=3))
cvs.add_budget(2.0, 3.0, 30.0, fill=True)
# 均衡點與擴張路徑
cvs.add_equilibrium(eq, show_ray=True)
cvs.save("show_save.png")

    樣式

    LineStyle 定義線型，ArrowStyle 定義箭頭樣式，Stroke 統一設定線寬、線型、顏色與箭頭，可套用於座標軸、預算線、路徑與投影線。

    線條樣式

    LineStyle
    SOLIDLineStyle

    實線。

    DASHEDLineStyle

    虛線。

    DOTTEDLineStyle

    點線。

    DASHDOTLineStyle

    點劃線。

    提供實線、虛線、點線與點畫線（參見四種線條樣式）。座標軸接受列舉值或對應字串；其他線條透過 Stroke(style=...) 設定。 LineStyle 就是 MosaicKit 的 DashStyle，沿用舊名稱。

    from mosaickit import CanvasGrid

from utility_viz import Canvas, Config, LineStyle

# 載入圖形設定
Config.load("econ-viz.toml").use()

styles = [
    LineStyle.SOLID,
    LineStyle.DASHED,
    LineStyle.DOTTED,
    LineStyle.DASHDOT,
]
titles = ["實線", "虛線", "點線", "點劃線"]
panels = [
    Canvas(
        title=title,
        x_label="$x$",
        y_label="$y$",
        x_label_pos="bottom",
        x_line_style=style,
        y_line_style=style,
    )
    for style, title in zip(styles, titles)
]
for panel in panels:
    # 小畫布
    panel.spec = panel.spec.replace(width=2.2, height=2.0)
CanvasGrid([panels]).save("line_styles.png")

    箭頭樣式

    ArrowStyle
    SIMPLEArrowStyle

    開口箭頭（->）。

    TRIANGLEArrowStyle

    實心三角形（-|>），預設值。

    FANCYArrowStyle

    彎曲、漸細的箭頭。

    WEDGEArrowStyle

    細楔形箭頭。

    提供四種箭頭樣式（參見四種箭頭樣式）。座標軸透過 x_arrow_style、y_arrow_style 設定；其他線條透過 Stroke(arrow=...) 設定。 ArrowStyle 是 MosaicKit 的；SIMPLE 即 OPEN，仍接受 "->" 與 "-|>"。

    from mosaickit import CanvasGrid

from utility_viz import ArrowStyle, Canvas, Config

# 載入圖形設定
Config.load("econ-viz.toml").use()

styles = [
    ArrowStyle.SIMPLE,
    ArrowStyle.TRIANGLE,
    ArrowStyle.FANCY,
    ArrowStyle.WEDGE,
]
titles = ["簡單", "三角形", "花式", "楔形"]
panels = [
    Canvas(
        title=title,
        x_label="$x$",
        y_label="$y$",
        x_label_pos="bottom",
        x_arrow_style=style,
        y_arrow_style=style,
    )
    for style, title in zip(styles, titles)
]
for panel in panels:
    # 小畫布
    panel.spec = panel.spec.replace(width=2.2, height=2.0)
CanvasGrid([panels]).save("arrow_styles.png")

    Stroke

    Stroke(
    width=float,
    style=LineStyle,
    color=str,
    arrow=ArrowStyle,
    opacity=float
)

    設定線寬、線型、顏色、箭頭與透明度。未指定的欄位沿用目前主題。opacity 的有效範圍為 0 至 1。

    Axis

    Axis

    集中設定單一座標軸的標籤、標籤位置與線條。Canvas、Figure、DemandDiagram 與 EdgeworthBox 均接受 x_axis 與 y_axis。若同時傳入簡寫參數，Axis 中已設定的欄位優先。

    from utility_viz import Axis, Canvas, Label, Stroke

cvs = Canvas(
    x_axis=Axis(
        label=Label(text="x_1", fontsize=16),
        label_position="bottom",
        stroke=Stroke(width=1.2),
    ),
    y_axis=Axis(label="x_2"),
)

    Marker 與 Label

    Marker

    設定標記點的顏色、大小、形狀與透明度。shape 接受 matplotlib 的標記字串，例如 "o"、"s"、"^"、"D" 與 "*"。

    Label

    設定文字、位置、位移、顏色、字級、可見性與透明度。位置可為上、下、左、右或四個角落；Label(visible=False) 隱藏對應文字。

    from utility_viz import Label, Marker

cvs.add_equilibrium(
    eq,
    marker=Marker(shape="s", size=8),
    label=Label(position="bottom-left", offset=8),
)
cvs.add_point(
    12,
    2,
    marker=Marker(color="black", shape="D"),
    label=Label(text="A", position="left", fontsize=14),
)

    top、bottom、left 與 right 會在標籤自動定位之後再微調位置：可傳入點數，或帶單位的字串，例如 "10pt"、"0.5em"（以標籤字級為單位）或 "2mm"。位置仍由自動定位決定，之後加入的標籤也會避開移動後的標籤。在 econ-viz.toml 的 [utility.label.<name>] 寫入 top = "2pt"，可為該類標籤設定預設值（單位可用 pt、mm、cm 或 in，不支援 em）；標籤本身指定的值會取代該方向的預設值。未設定微調時，所有圖形維持不變。

    from utility_viz import Label

cvs.add_equilibrium(eq, label=Label(top="10pt"))
cvs.add_point(5, 3, label=Label(text="A", left="6pt"))

    Fill

    Fill

    設定陰影區域的顏色與透明度。alpha 是 opacity 的相容簡寫；同一次呼叫不得傳入不同的 alpha 與 opacity。

    from utility_viz import Fill

cvs.add_budget(
    2,
    3,
    30,
    fill=Fill(color="lightgrey", opacity=0.4),
)

    串接呼叫

    add_* 方法支援串接呼叫，最後以 save() 匯出：

    Canvas(x_max=20, y_max=15).add_utility(
    model, levels=lvls
).add_budget(2.0, 3.0, 30.0, fill=True).add_equilibrium(
    eq, show_ray=True
).save(
    "figure.png"
)
